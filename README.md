# B-tree Visualizer

A DBMS project that teaches B-tree indexing. Build a B-tree key by key and watch every step of insert, delete and search: walking down, splitting a full node, borrowing from a sibling, merging two nodes.

**Live site:** _(https://dhruv2025-del.github.io/btree-visualizer/)_

## Pages

| Page | What it does |
| --- | --- |
| Visualizer | Insert, delete and search for orders 3 to 7, with step-by-step playback, pseudocode highlighting, undo and redo |
| QUIZ | Choose the number of questions and Easy, Medium or Hard; one question at a time with explanations and a final score |
| COMPETITIVE EXAM | 58 solved questions (GATE-style and practice) with options, answers and step-by-step solutions |
| Download | A report of your session as PDF, Word document or text |
| Help | A step-by-step user manual |
| Developed By | The team and the guide, Dr. Swaminathan A, Assistant Professor |
| Learn | Concept explanation, video, animation and references |

A Day Mode / Night Mode switch is at the top right of every page.

## Run it on your own computer

1. Install Python 3.
2. Double-click `start-site.bat` (or run `python server.py`).
3. Open http://localhost:3000.

The site is plain HTML, CSS and JavaScript with no build step and no server code, so it also runs on GitHub Pages as it is.

## Team details

Names, register numbers and photographs are in `site-data.js`. The Developed By page has an "Edit the team details" form that writes a new copy of that file.

## Notes

- The quiz questions are generated by the program (their answers come from the B-tree engine or from formulas). No online AI service is used.
- The exam questions tagged with a GATE paper were checked against published solutions and are re-worded.
- `vendor/jspdf.umd.min.js` is jsPDF (MIT licence). The fonts in `fonts/` are under the SIL Open Font License. Licence files are included.
